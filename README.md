# BlackForge AI

Autonomous bug discovery, repair, and verification — **Break it. Fix it. Prove it.**

## Analysis Console (Phase 1)

The working UI lives in [`code/blackforge`](code/blackforge):

```bash
cd code/blackforge
npm install
npm run dev
```

Open **http://127.0.0.1:4827** and click **Run Analysis**. See [`code/blackforge/README.md`](code/blackforge/README.md) for details.
